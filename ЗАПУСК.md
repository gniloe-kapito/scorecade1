# Как запустить Scorecade на своём компьютере

Полный исходный код сайта. Ниже — всё, что нужно, чтобы поднять его локально.

## Что понадобится

- **Bun** (проще всего) — https://bun.sh → одна команда установки.
  Или **Node.js 20+** с npm — тоже подойдёт (см. вариант Б).

## Вариант А — Bun (рекомендую)

```bash
# 1. Зайти в папку проекта
cd scorecade

# 2. Установить зависимости
bun install

# 3. Создать файл окружения из шаблона
cp .env.example .env

# 4. Создать базу данных (SQLite-файл появится в db/)
bun run db:push

# 5. Запустить сайт
bun run dev
```

Откройте http://localhost:3000 — готово.

## Вариант Б — Node.js + npm

```bash
cd scorecade
npm install
cp .env.example .env
npx prisma db push --accept-data-loss
npm run dev
```

> Скрипт `dev` в этом проекте записывает лог в `dev.log` — это нормально.

## Продакшн-сборка (по желанию)

```bash
bun run build
bun run start
```

## Частые вопросы

**Где хранится база?**
В файле `db/custom.db` (SQLite). Ничего отдельного ставить не нужно.

**Как сбросить базу до пустой?**
Удалите `db/custom.db` и снова выполните `bun run db:push`.

**Нужен ли ключ kappa.lol для аватарок?**
Нет, загрузки работают и без ключа. Если у вас есть личный ключ,
раскомментируйте строку `KAPPA_API_KEY=` в `.env` и впишите его.

**Из чего состоит проект?**

| Папка / файл | Что там |
|---|---|
| `src/app` | Страницы и все API-роуты (Next.js App Router) |
| `src/components/app` | Компоненты сайта: шапка, колесо оценки, виды страниц |
| `src/components/ui` | Библиотека компонентов shadcn/ui |
| `src/lib` | Логика: Steam API, авторизация, кэш, загрузка картинок на kappa.lol |
| `prisma/schema.prisma` | Описание таблиц базы данных |
| `public` | Иконки, манифест PWA, service worker |

**Как выложить в интернет?**
Пошаговые инструкции — в файлах `../GITHUB.md` и `../CLOUDFLARE.md`
(в папке «готово», уровнем выше).
